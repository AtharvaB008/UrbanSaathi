# UrbanSaathi

UrbanSaathi is a smart urban exploration and decision-support platform focused on Mangaluru.

## Project Goals
- Visualize population density across city wards.
- Map essential facilities such as healthcare, education, parks, and transport.
- Help residents and property buyers understand neighbourhoods.

## Tech Stack
- Python
- Streamlit
- Folium
- Geospatial datasets and APIs

## Development
This project is under development as part of a hackathon.

## Team Workflow
- Use feature branches for new modules.
- Submit pull requests before merging into main.
- Keep API keys and large datasets out of Git.
